# 體驗轉介率計算工具（LALASO）

上傳 Bookfast 報表，依館別（西屯／北屯／兩館）與課程（親子／幼兒／兒童）計算轉介率。

- 支援「團體課預約報表」與「團體課表預約明細簽到版」兩種格式
- 轉介率 = 分子票券張數 ÷ 正式生人數（正式生由老師手動輸入，會記在瀏覽器）
- 預設分子：體驗券＋單次券（N48、N55、N56、N94、N95、N96、N39、N59、N66），不含水上樂園、自游時光
- 「計算設定」可用勾選方式調整分子／分母票券與所屬課程；分母也可改用勾選的票券張數
- 以預約計算，每筆預約計 1 張，不論是否到課；可依整段期間／每月／每週檢視，可匯出 CSV
- 檔案只在瀏覽器內處理，不會上傳到任何伺服器

## 部署（GitHub Pages）
1. 新增 repo，上傳 `index.html`
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`
3. 約 1 分鐘後網址為 `https://<帳號>.github.io/<repo名稱>/`
